# Video: Sets, Relations, and Functions Explained

This video covers the foundational building blocks of discrete mathematics: set notation and operations (union, intersection, complement, Cartesian product), Venn diagrams, relations and their properties (reflexivity, symmetry, transitivity), equivalence classes, and the formal definitions of functions including injectivity, surjectivity, and bijectivity.

**Key takeaways:**

- Set-builder notation and how to translate English descriptions into formal set expressions.
- How the laws of set algebra (De Morgan's, distributive, absorption) mirror boolean logic.
- Why equivalence relations partition a set into disjoint equivalence classes — a concept used directly in union-find data structures.
- The difference between injective ("one-to-one"), surjective ("onto"), and bijective functions, with visual intuition.
- Cantor's diagonal argument and what it tells us about countable vs. uncountable infinities.

This is essential background before studying group theory, type systems, or the foundations of database query languages.
