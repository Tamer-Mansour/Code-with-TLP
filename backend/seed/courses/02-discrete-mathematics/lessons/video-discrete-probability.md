# Video: Discrete Probability — From Sample Spaces to Bayes' Theorem

This video develops discrete probability from first principles: sample spaces, events, probability axioms, conditional probability, independence, Bayes' theorem, random variables, and expected value, with intuitive examples and pitfalls.

**Key takeaways:**

- A sample space Ω is the set of all possible outcomes; an event A is a subset of Ω; P(A) = |A|/|Ω| for uniform distributions.
- Conditional probability P(A|B) = P(A ∩ B) / P(B) — the probability of A given that B has occurred.
- Bayes' theorem: P(A|B) = P(B|A) · P(A) / P(B) — how to update beliefs after observing evidence.
- Independence: A and B are independent iff P(A ∩ B) = P(A)·P(B); be careful not to confuse independence with mutual exclusivity.
- Expected value E[X] = Σ x · P(X=x); linearity of expectation means E[X+Y] = E[X]+E[Y] even for dependent variables.

The video demonstrates Bayes' theorem with the classic medical test example (false positives), and uses linearity of expectation to compute the expected number of comparisons in randomized algorithms.
