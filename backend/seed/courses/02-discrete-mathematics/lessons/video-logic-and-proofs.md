# Video: Logic and Proofs — A Visual Introduction

This video provides a concise, visually driven walkthrough of propositional logic, truth tables, logical connectives (AND, OR, NOT, implication, biconditional), and the core proof techniques: direct proof, contrapositive, contradiction, and mathematical induction.

**Key takeaways:**

- How to build truth tables for compound propositions and verify tautologies.
- The equivalence between an implication `p → q` and its contrapositive `¬q → ¬p`.
- Why proof by contradiction works: assuming ¬P and deriving a falsehood forces P to be true.
- The two-step structure of induction (base case + inductive step) and where it applies.
- How these techniques are the daily toolkit for algorithm correctness proofs and complexity analysis.

Watch for the worked examples on proving `√2` is irrational and the classic formula `1 + 2 + ... + n = n(n+1)/2` by induction.
