# Exercise: Word Frequency Counter

Given a paragraph of text (single line, lowercase words, only letters and spaces), count how many times each word appears and print the results sorted by frequency descending, then alphabetically for ties.

**Input format:**
- One line containing space-separated words (all lowercase, only `a-z` and spaces).

**Output format:**
- One line per word: `<word> <count>`, sorted by count descending, then word ascending for ties.

**Example:**

Input:
```
the cat sat on the mat the cat
```

Output:
```
the 3
cat 2
mat 1
on 1
sat 1
```
