# Class Instance Counter

You are given **N** student records. Read them, then print each student's information followed by a total count.

## Input

- First line: integer **N** (1 ≤ N ≤ 50)
- Next N lines: `<name> <age>` — a name (no spaces) and an integer age, separated by a single space

## Output

- N lines of the form: `Name: <name>, Age: <age>` — in the same order as input
- Final line: `Total students: <N>`

## Example

**Input:**
```
3
Alice 20
Bob 22
Carol 19
```

**Output:**
```
Name: Alice, Age: 20
Name: Bob, Age: 22
Name: Carol, Age: 19
Total students: 3
```
