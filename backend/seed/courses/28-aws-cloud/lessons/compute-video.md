# AWS EC2, Lambda, and Fargate - Compute Deep Dive Video

This freeCodeCamp video walks through AWS compute options in depth: launching and configuring EC2 instances, writing and deploying Lambda functions, and running containerized workloads on Fargate.

**Key topics covered:**

- EC2 instance types, AMIs, key pairs, and security groups
- EBS volume types and snapshots
- Lambda runtimes, triggers, and deployment packaging
- ECS task definitions and Fargate services
- Auto Scaling Groups and Load Balancers for EC2

**Suggested use:** Watch after completing the EC2/EBS/S3 reading lesson. Pause and try the CLI commands shown — having an AWS Free Tier account open alongside makes the concepts concrete.
