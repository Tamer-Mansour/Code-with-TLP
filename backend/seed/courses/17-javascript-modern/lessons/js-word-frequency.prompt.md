# Word Frequency Counter

Given a single line of space-separated lowercase words, count how many times each unique word appears and print the results sorted **alphabetically**, one entry per line in the format:

```
word count
```

## Input

A single line of space-separated lowercase words (letters only, no punctuation).

## Output

Each unique word and its count, sorted alphabetically, one per line, separated by a single space.

## Example

**Input:**
```
the cat sat on the mat the cat
```

**Output:**
```
cat 2
mat 1
on 1
sat 1
the 3
```

## Constraints

- All words are lowercase letters only.
- At least one word is guaranteed.
- Up to 1000 words.
