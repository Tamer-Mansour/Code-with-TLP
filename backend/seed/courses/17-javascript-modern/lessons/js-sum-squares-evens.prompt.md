# Sum Squares of Evens

## Input

A sequence of integers separated by whitespace (spaces or newlines).

```
1 2 3 4 5 6
```

## Output

A single integer: the sum of squares of every even integer in the input. If there are no evens (or no input), print `0`.

## Examples

Input: `1 2 3 4 5 6` → Output: `56` (4 + 16 + 36)

Input: `1 3 5 7` → Output: `0`

Input: `-2 -1 0 1 2` → Output: `8` (4 + 0 + 4)

Input: (empty) → Output: `0`

## Constraints

- Each integer fits in a 32-bit signed range.
- The total count is at most 10 000.
