# Video: IP Addressing, Subnetting, and the Network Layer

This video teaches IP addressing from the ground up: binary representation of IPv4 addresses, classful vs. classless (CIDR) addressing, subnet mask arithmetic, and how routers use routing tables to forward packets. It includes worked subnetting examples and explains NAT and IPv6 basics.

Key takeaways: every IPv4 address is 32 bits split into a network portion and host portion by the prefix length; CIDR notation (e.g., 192.168.1.0/24) replaced classful addressing to slow IPv4 exhaustion; NAT allows many private hosts to share one public IP. The video walks through manual subnet calculations you will apply in the exercises.

Timestamps: 0:00 — IPv4 address format; ~20 min — CIDR and subnet masks; ~45 min — subnetting worked examples; ~1:05 — routing tables and longest prefix match; ~1:25 — NAT; ~1:40 — IPv6 introduction.
