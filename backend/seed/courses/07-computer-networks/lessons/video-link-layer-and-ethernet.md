# Video: The Link Layer — Ethernet, MAC, and Switches

This video explains how data frames move across a single link, covering Ethernet frame structure, MAC addresses, how switches learn and forward frames using a MAC address table, ARP (Address Resolution Protocol), and error detection with CRC checksums.

Key takeaways: Ethernet frames encapsulate IP packets; MAC addresses are 48-bit hardware identifiers used for local delivery; ARP maps IP addresses to MAC addresses within a subnet; switches operate at Layer 2 and flood, learn, and filter frames to build an efficient forwarding table. Wireshark captures of ARP and Ethernet frames are included.

Timestamps: 0:00 — Ethernet frame structure; ~15 min — MAC addresses and ARP; ~30 min — how switches work (MAC table flooding and learning); ~45 min — CRC error detection; ~55 min — VLANs overview.
