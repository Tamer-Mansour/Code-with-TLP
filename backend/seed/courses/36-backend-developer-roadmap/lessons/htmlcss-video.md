# Video: HTML & CSS Full Course

This video walks you through HTML5 document structure and CSS3 styling from the ground up, giving you the front-end vocabulary every backend developer needs when reading, debugging, or writing server-rendered templates.

## What you'll learn

- How browsers parse an HTML document and build the DOM tree
- Semantic elements (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) and why they matter for accessibility and SEO
- The CSS box model — `content`, `padding`, `border`, and `margin` — and how they affect layout
- Selectors, specificity, and the cascade (element, class, ID, pseudo-class)
- Flexbox for one-dimensional layouts and CSS Grid for two-dimensional layouts
- Responsive design with media queries and relative units (`rem`, `%`, `vh`)

## Key takeaways

- Every visible element is a rectangular box; mastering the box model removes most layout confusion
- Semantic HTML is not optional — it directly impacts screen readers and search ranking
- Flexbox and Grid complement each other; use Flexbox for components, Grid for page structure
- A single `<link rel="stylesheet">` tag is all that connects an HTML file to a CSS file

## Follow-along checklist

- [ ] Create `index.html` with correct `<!DOCTYPE html>` declaration and `<meta charset="UTF-8">`
- [ ] Add semantic landmark elements and verify structure in browser DevTools
- [ ] Link an external `styles.css` and confirm it loads in the Network tab
- [ ] Build a two-column layout with Flexbox, then rebuild it with Grid
- [ ] Add one `@media (max-width: 768px)` rule and test on a narrow viewport
