# FizzBuzz

Read a single integer `n` from standard input. Print the numbers from `1` to `n`
inclusive, **one per line**, applying the classic FizzBuzz rules:

- If the number is divisible by **15**, print `FizzBuzz`.
- Otherwise if divisible by **3**, print `Fizz`.
- Otherwise if divisible by **5**, print `Buzz`.
- Otherwise print the number itself.

## Input

```
5
```

## Output

```
1
2
Fizz
4
Buzz
```

## Notes

- `1 <= n <= 1000`.
- Print each entry on its own line, with no trailing blank line.
