# React Frontend Development — Course Introduction

This video is the official freeCodeCamp full React course. It walks through every fundamental concept from zero, including JSX, components, props, state, hooks, and more.

**Key topics covered:**
- Setting up a React project with Vite
- Writing your first component and rendering JSX
- Props, state with `useState`, and side effects with `useEffect`
- Building a small project end-to-end

Watch the first 30–60 minutes as an orientation before reading the following lessons. Return to specific sections whenever you want a visual walkthrough of a concept.
