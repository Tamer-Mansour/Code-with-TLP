# React Router v6 — Video Walkthrough

This video by freeCodeCamp covers React Router version 6 from scratch, including route setup, nested routes, protected routes, and the most important hooks.

**Key topics covered:**
- Installing and configuring React Router v6 in a Vite project
- Defining routes with `<Routes>` and `<Route>`, including the catch-all `*` route
- Using `<Link>`, `useNavigate`, `useParams`, and `useSearchParams`
- Building a shared layout with `<Outlet>` and nested routes
- Implementing protected routes that redirect unauthenticated users

Watch this video alongside the reading lesson to see every concept applied in a real project. Pay special attention to the nested routes and layout section, which is the most commonly misunderstood part of v6.
