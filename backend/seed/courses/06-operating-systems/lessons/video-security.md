# Video: OS Security — Attacks and Defenses

This video unit covers how operating systems protect against malicious code, the anatomy of common exploits, and the hardware and software defenses that modern OSes deploy.

## What You Will Learn

- Protection rings and the user/kernel privilege boundary
- Authentication models: passwords, tokens, biometrics, and multi-factor
- Access control: discretionary (DAC) vs. mandatory (MAC), ACLs vs. capabilities
- Buffer overflow attacks: stack smashing, heap overflows, format string bugs
- Return-to-libc and Return-Oriented Programming (ROP)
- OS defenses: ASLR, stack canaries, NX/DEP (W^X)
- Linux security modules: SELinux and AppArmor
