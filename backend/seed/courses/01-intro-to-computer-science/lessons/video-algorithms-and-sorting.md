# Video: Algorithms — Searching, Sorting, and Big-O

This video from CS50 introduces the concept of an algorithm as a step-by-step problem-solving procedure, demonstrates linear and binary search, walks through bubble sort and merge sort, and introduces Big-O notation for measuring algorithmic efficiency.

**Key topics covered:**
- What makes a procedure an algorithm: correctness, finiteness, and determinism
- Linear search (O(n)) vs binary search (O(log n)) — when each applies
- Bubble sort: adjacent swaps, worst-case O(n²), and why it is a useful teaching tool
- Merge sort: divide-and-conquer, O(n log n), and the trade-off with extra memory
- Big-O notation: ignoring constants and lower-order terms to compare growth rates
- Pseudocode as a language-independent way to express algorithms

**Recommended timestamps to focus on:**
- 0:00 – Defining algorithms and pseudocode
- ~8:00 – Linear vs binary search animated
- ~18:00 – Bubble sort step-by-step
- ~28:00 – Merge sort and recursion intuition
- ~38:00 – Big-O notation explained
