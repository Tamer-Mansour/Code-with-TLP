# Video: Boolean Logic and Logic Gates

This video covers Boolean algebra and digital logic gates — the physical building blocks that implement AND, OR, NOT, and XOR operations inside every processor chip.

**Key topics covered:**
- Boolean values (True/False, 1/0) and their connection to transistor on/off states
- The six fundamental gates: AND, OR, NOT, NAND, NOR, XOR — with truth tables
- How gates are combined into half-adders and full-adders that perform binary addition
- Building a 1-bit comparator and a simple multiplexer from gates
- Why NAND gates alone can implement any Boolean function (functional completeness)

**Recommended timestamps to focus on:**
- 0:00 – Boolean algebra laws (identity, complement, De Morgan's)
- ~10:00 – Gate symbols and truth tables
- ~20:00 – Adder circuits built from gates
- ~30:00 – Practical implications for CPU arithmetic units
