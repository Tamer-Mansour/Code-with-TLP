# Video: How Computers Represent Data

This video from CS50 (Harvard's Introduction to Computer Science) demonstrates how computers encode text, images, and audio as sequences of bits — covering ASCII, Unicode, RGB pixels, and the concept of file formats.

**Key topics covered:**
- How integers and negative numbers (two's complement) are stored in fixed-width registers
- ASCII and Unicode: mapping characters to numeric codes
- How a digital image is a 2-D grid of RGB pixel values, each stored as three bytes
- How audio is represented as a sequence of amplitude samples (PCM)
- Lossless vs lossy compression: ZIP vs JPEG vs MP3

**Recommended timestamps to focus on:**
- 0:00 – Integers and two's complement overview
- ~12:00 – ASCII table and Unicode code points
- ~22:00 – Images as pixel grids and RGB values
- ~30:00 – Sound sampling and compression basics

As you watch, note how every type of data ultimately reduces to a number — the only question is how many bits are allocated and how those bits are interpreted.
