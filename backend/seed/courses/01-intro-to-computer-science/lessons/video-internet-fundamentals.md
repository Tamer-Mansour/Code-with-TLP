# Video: How the Internet Works

This video from freeCodeCamp.org covers how data travels across the internet — from physical cables and routers to IP addresses, DNS, TCP/IP, and the HTTP request-response cycle that powers every web page you visit.

**Key topics covered:**
- Physical infrastructure: copper cables, fiber optics, and wireless radio
- IP addresses (IPv4 and IPv6) and how routers forward packets
- DNS: translating human-readable domain names to IP addresses
- TCP vs UDP: reliable ordered delivery vs low-latency streaming
- The HTTP request-response cycle: methods, status codes, and headers
- HTTPS and TLS: why encryption matters for web security

**Recommended timestamps to focus on:**
- 0:00 – Physical network layers and packet switching
- ~10:00 – IP addresses and routing tables
- ~18:00 – DNS resolution walk-through
- ~26:00 – TCP handshake and reliable delivery
- ~35:00 – HTTP/HTTPS and the browser's journey from URL to rendered page
