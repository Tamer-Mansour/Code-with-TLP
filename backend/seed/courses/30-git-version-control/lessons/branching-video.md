# Git Branching and Merging — Video Lesson

This video walks through Git branching, merging, and resolving conflicts in a hands-on demonstration. It is ideal for reinforcing the concepts from the reading lessons with real terminal examples.

**Key topics covered in the video:**

- Creating and switching branches (`git switch -c`, `git branch`)
- Visualizing the commit graph with `git log --graph --all --oneline`
- Performing fast-forward vs. three-way merges and understanding when each occurs
- Resolving merge conflicts step by step in a text editor
- Rebasing a feature branch onto main to produce a linear history

**What to pay attention to:**

Watch how the branch pointer moves after each commit, and notice how `git log --graph` shows the divergence and reconvergence of branches after a merge.
