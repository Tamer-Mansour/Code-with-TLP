# Git and Version Control — Course Introduction

This video provides a full introduction to Git and version control from the ground up. It covers why version control exists, how Git was created by Linus Torvalds, and walks through the core concepts you need before diving into hands-on practice.

**Key topics covered:**

- What version control is and why every developer needs it
- The difference between centralized (SVN) and distributed (Git) version control
- Installing Git on Windows, macOS, and Linux
- The Git data model: blobs, trees, commits, and references
- Your first repository: `git init`, `git add`, `git commit`

- 0:00 — What is version control?
- 10:00 — Installing and configuring Git
- 25:00 — Creating your first repository and making commits
- 45:00 — Viewing history with `git log`
