# Git Team Workflows — Video Lesson

This video explains the major team branching strategies used in professional software development, including GitHub Flow, GitFlow, and trunk-based development. It demonstrates the trade-offs between each approach and shows how to configure branch protection rules in GitHub.

**Key topics covered in the video:**

- Why branching strategies matter in team environments
- GitHub Flow: branch → PR → merge → deploy
- GitFlow: feature, develop, release, and hotfix branches explained
- Trunk-based development and continuous integration
- Setting up branch protection rules and required status checks on GitHub

**What to watch for:**

Pay attention to how each workflow handles the trade-off between deployment frequency and stability. The choice of workflow depends heavily on how often your team deploys and how many versions you maintain simultaneously.
