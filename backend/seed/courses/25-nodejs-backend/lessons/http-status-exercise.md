# Exercise: HTTP Status Code Classifier

Given a list of HTTP status codes, classify each one as `1xx`, `2xx`, `3xx`, `4xx`, or `5xx` and output the category label and a brief standard name for that class.

This exercise reinforces understanding of HTTP response semantics, which every API developer must know instinctively.

Read each status code on a separate line. For each code, output one line: `<code> <category>` where category is one of `Informational`, `Success`, `Redirection`, `Client Error`, or `Server Error`.
