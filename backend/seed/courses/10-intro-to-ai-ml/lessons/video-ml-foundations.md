# Video: Machine Learning Foundations

This video explains what machine learning is, contrasts the three learning paradigms (supervised, unsupervised, reinforcement), and demonstrates the bias-variance tradeoff with a polynomial fitting demo.

Key takeaways:
- The fundamental ML recipe: choose a model class, define a loss, minimise it on training data, and measure performance on held-out test data.
- Overfitting looks like near-zero training loss but high test loss; underfitting is high loss on both.
- Regularisation (L1, L2) and cross-validation are the primary tools for managing generalisation.
