# Video: Supervised Learning — Regression, Classification, and Trees

This video covers linear and logistic regression from scratch, then builds a decision tree by hand using information gain, illustrating how each algorithm draws decision boundaries.

Key takeaways:
- Linear regression minimises mean squared error; gradient descent adjusts weights one step at a time.
- Logistic regression applies the sigmoid function to produce calibrated class probabilities.
- Decision trees recursively split on the feature that maximises information gain (reduction in entropy).
