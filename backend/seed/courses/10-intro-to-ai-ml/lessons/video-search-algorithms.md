# Video: Search Algorithms — BFS, DFS, and A*

This video walks through uninformed search (BFS and DFS), introduces heuristics, and builds up to the A* algorithm with a worked grid-navigation example.

Key takeaways:
- BFS guarantees the shortest path in unweighted graphs; DFS uses less memory but may not find the shortest path.
- A heuristic h(n) must be **admissible** (never overestimates) for A* to guarantee optimality.
- A* explores far fewer nodes than BFS on large state spaces with a good heuristic.
