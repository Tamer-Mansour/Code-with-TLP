# Video: Neural Networks and Deep Learning

This video builds a two-layer neural network from scratch in Python, walks through forward propagation, computes the loss, and then explains backpropagation using the chain rule to update weights.

Key takeaways:
- Every neuron computes a weighted sum followed by a non-linear activation (ReLU, sigmoid, tanh).
- Backpropagation applies the chain rule layer by layer to compute gradients efficiently.
- Batch normalisation, dropout, and learning rate schedules are the key practical tricks for stable training.
