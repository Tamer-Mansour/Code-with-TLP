# Exercise: Word Frequency Counter

Given a block of text, count how many times each unique word appears (case-insensitive, ignoring punctuation). Print each `word: count` pair, one per line, sorted **alphabetically** by word.

## Input format

A single line of text (may contain punctuation and mixed case).

## Output format

One `word: count` entry per line, sorted alphabetically.

## Example

**Input:**
```
Hello world hello Python world world
```

**Output:**
```
hello: 2
python: 1
world: 3
```
