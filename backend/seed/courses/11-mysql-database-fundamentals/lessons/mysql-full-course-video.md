# MySQL Full Course – Video Overview

This video is a comprehensive introduction to MySQL from freeCodeCamp.org. It walks you through installation, database and table creation, all major SQL statements (SELECT, INSERT, UPDATE, DELETE), joins, indexes, and stored procedures.

**Key takeaways:**

- How to install MySQL on Windows, macOS, and Linux and verify the connection.
- Writing queries from simple SELECTs to multi-table JOINs and aggregations.
- Using constraints (PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL) to keep data clean.
- Creating and dropping indexes and reading basic EXPLAIN output.

**Approximate timestamps:**

- 0:00 – Introduction and installation
- 15:00 – Creating databases and tables
- 45:00 – SELECT, WHERE, ORDER BY, LIMIT
- 1:10:00 – JOINs (INNER, LEFT, RIGHT)
- 1:40:00 – Aggregate functions and GROUP BY
- 2:05:00 – Indexes and query optimization
- 2:30:00 – Stored procedures and triggers
