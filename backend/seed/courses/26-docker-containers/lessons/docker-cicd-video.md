# Video: Docker CI/CD Full Course

This video by TechWorld with Nana walks through a complete Docker CI/CD pipeline — from writing a Dockerfile to pushing images and deploying to a server. It covers Docker fundamentals, image building, registries, and integrating Docker into automated pipelines.

Key topics covered in the video:
- Docker architecture review and image lifecycle
- Building and tagging images for different environments
- Pushing and pulling from Docker Hub and private registries
- Setting up an automated CI pipeline that builds, tests, and publishes Docker images
- Deploying updated containers to a remote server using Docker Compose

Watch this after completing the reading lessons to see all the concepts working together end-to-end in a realistic project setup.
