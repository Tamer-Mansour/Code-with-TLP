# Video: Docker Full Course for Beginners

This is the freeCodeCamp Docker full course taught by Nelson (Bret Fisher). It covers Docker from the ground up — what containers are, how to run your first container, write Dockerfiles, manage volumes, set up multi-container applications with Compose, and understand networking.

Key topics and approximate timestamps:
- 0:00 – What is Docker and why use containers
- 15:00 – Installing Docker and running your first container
- 35:00 – Docker images, layers, and Dockerfile fundamentals
- 1:10:00 – Networking: bridge, host, and user-defined networks
- 1:45:00 – Volumes and persistent data
- 2:15:00 – Docker Compose and multi-container applications

Watch this video alongside or before the reading lessons to build a strong visual mental model of how Docker components fit together.
