# Video: Go Standard Library Tour

This video provides a practical walkthrough of the Go standard library, covering the most commonly used packages for real-world Go development.

Key topics covered include the `fmt`, `os`, `io`, `bufio`, `strings`, `strconv`, `encoding/json`, `net/http`, and `time` packages. The video demonstrates how to write idiomatic Go using only the standard library — reading files line by line, parsing JSON, formatting output, and building a small HTTP server. By the end you will be comfortable navigating `pkg.go.dev` and the `go doc` tool to look up any package independently.
