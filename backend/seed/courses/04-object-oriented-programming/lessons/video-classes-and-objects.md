# Video: Classes and Objects in Python

This video introduces the core building blocks of Object-Oriented Programming — classes, instances, attributes, and methods — using Python as the teaching language. It walks through creating your first class from scratch and demonstrates how state and behavior are bundled together inside an object.

**Key takeaways:**

- How a `class` definition is a blueprint and an instance is a live object with its own state.
- The role of `__init__` as the constructor and `self` as the reference to the current instance.
- The difference between instance attributes (per-object state) and class attributes (shared across all instances).
- How to define and call methods, including special (dunder) methods like `__repr__` and `__str__`.
- Practical examples demonstrating why OOP produces cleaner, more maintainable code than scattered variables and free functions.
