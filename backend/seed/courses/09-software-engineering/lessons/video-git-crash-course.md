# Video: Git and GitHub Full Crash Course

This video covers Git from the ground up, moving quickly from first `git init` through branching, merging, rebasing, and pull request workflows on GitHub. It is the practical complement to the reading lessons in this module, showing every command executed in a real terminal against a real repository.

**Key takeaways:**
- Core Git data model: how commits form a directed acyclic graph (DAG) of snapshots, not diffs.
- Essential daily commands: `clone`, `add`, `commit`, `push`, `pull`, `fetch`, `status`, `log`, `diff`.
- Branching and merging: creating feature branches, resolving merge conflicts in a text editor, and fast-forward vs. three-way merges explained visually.
- Rewriting history safely: `git rebase`, interactive rebase (`rebase -i`), `git reset`, and when each is appropriate.
- GitHub pull request workflow: forking, opening a PR, requesting reviews, addressing feedback, and squash-merging.
