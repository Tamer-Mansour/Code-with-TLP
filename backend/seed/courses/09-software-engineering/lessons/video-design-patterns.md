# Video: Design Patterns Explained

This video walks through the most important Gang of Four (GoF) design patterns using concrete code examples in multiple languages. It groups patterns by intent — creational, structural, and behavioral — and demonstrates when each pattern solves a real problem versus when it adds unnecessary complexity.

**Key takeaways:**
- Creational patterns: Singleton (and why it makes testing harder), Factory Method, and Builder for constructing complex objects step by step.
- Structural patterns: Adapter (wrapping a third-party API to match your interface), Decorator (adding behavior without subclassing), and Facade (simplifying a complex subsystem).
- Behavioral patterns: Observer (publish/subscribe event systems), Strategy (swappable algorithms at runtime), and Command (encapsulating actions for undo/redo).
- How to recognize pattern opportunities in existing code rather than forcing patterns upfront.
- The SOLID principles that underpin why these patterns work: Open/Closed, Liskov Substitution, Dependency Inversion.
