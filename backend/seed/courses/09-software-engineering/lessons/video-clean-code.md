# Video: Clean Code Principles

This video covers the core clean-code principles from Robert C. Martin's book and translates them into actionable habits. Using live refactoring sessions, the instructor transforms messy, real-world code into clean, readable, testable code one small step at a time.

**Key takeaways:**
- Naming: how to choose names for variables, functions, and classes that make intent obvious without comments.
- Function design: keeping functions short, doing one thing, and avoiding hidden side effects.
- Comments: when they help (explaining "why", not "what") and when they are a sign that the code itself needs to improve.
- Code smells catalogue: Long Method, Feature Envy, Data Clumps, Primitive Obsession — how to spot each and apply the right refactoring move.
- Practical refactoring techniques: Extract Function, Replace Magic Number with Constant, Introduce Guard Clause, and how to refactor safely under an existing test suite.
