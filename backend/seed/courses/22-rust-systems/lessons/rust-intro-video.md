# Rust Systems Programming — Course Introduction Video

This video provides a high-level tour of Rust: why it was created, how its ownership model eliminates memory bugs, and what you will build by the end of this course.

**Key takeaways:**

- Rust's borrow checker enforces memory safety at compile time with zero runtime cost.
- The `cargo` tool handles building, testing, formatting, linting, and dependency management in one place.
- You will progress from basic syntax through ownership, traits, error handling, concurrency, and the module system.

**Suggested timestamps to watch:**

- 0:00 — Why Rust? (safety vs. performance trade-off in C/C++)
- 5:00 — Installing Rust with `rustup` and a first `cargo new` project
- 12:00 — The ownership model explained in plain English
- 20:00 — What this course will cover and how to get the most from it
