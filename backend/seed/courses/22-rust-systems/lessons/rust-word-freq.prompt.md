# Word Frequency Counter

Read a single line from stdin containing space-separated words (case-sensitive). Count how many times each unique word appears. Print the results sorted alphabetically, one word per line, in the format:

```
word count
```

## Input format

A single line of space-separated words.

## Output format

One line per unique word: `<word> <count>`, sorted alphabetically by word.

## Example

**Input:**
```
the quick brown fox jumps over the lazy dog the fox
```

**Output:**
```
brown 1
dog 1
fox 2
jumps 1
lazy 1
over 1
quick 1
the 3
```
