# Exercise: C++ Type Deduction with auto and decltype

Practice understanding how `auto` and type deduction work in Modern C++. You will process a list of variable declarations and deduce their types according to C++ rules.

This exercise reinforces:
- `auto` drops top-level `const` and references
- `auto&` preserves references
- `decltype(x)` preserves the exact type including references
- Uniform initialization with braces

Understanding type deduction is fundamental to reading and writing templates, lambdas, and range-based for loops correctly.
