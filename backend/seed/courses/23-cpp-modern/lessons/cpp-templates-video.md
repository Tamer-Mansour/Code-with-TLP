# Video: C++ Templates and Generic Programming

This video covers C++ templates from first principles, starting with function templates and class templates and progressing to more advanced topics such as template specialization, variadic templates, and the SFINAE idiom. It demonstrates how the STL containers and algorithms are built entirely on top of templates.

Key takeaways include understanding how the compiler instantiates templates, how to write generic data structures like a stack or linked list, how to constrain templates with `static_assert` and (C++20) concepts, and common pitfalls like template bloat and long error messages. Timestamps guide you through each section so you can jump to the topic you need.

Watch this video after completing the Templates and Concepts reading lesson to see the ideas applied to real, working code examples.
