# Java Build Tools — Maven and Gradle (Video)

This video provides a practical walkthrough of the two dominant Java build tools: **Apache Maven** and **Gradle**. Understanding build tools is essential for working on any real Java project.

**Key topics covered in this video:**

- Maven project structure (`src/main/java`, `src/test/java`, `pom.xml`)
- The Maven lifecycle: `validate`, `compile`, `test`, `package`, `install`, `deploy`
- Dependency management and the Maven Central repository
- Gradle vs Maven: when to choose each, DSL syntax (Kotlin vs Groovy)
- Running tests, building fat JARs, and publishing artifacts

**Recommended timestamps:** Maven basics (0:00–20:00), Gradle quickstart (20:00–40:00), and multi-module projects (40:00 onward).
