# Array Statistics

Read an integer `N` on the first line, then `N` space-separated integers on the second line.

Print the **minimum**, **maximum**, and **average** of the array, each on a separate labelled line. Round the average to exactly **2 decimal places**.

## Input format

```
N
x1 x2 x3 ... xN
```

## Output format

```
Min: <min>
Max: <max>
Average: <avg>
```

## Example

**Input**
```
6
3 7 1 9 4 6
```

**Output**
```
Min: 1
Max: 9
Average: 5.00
```

## Constraints

- `1 <= N <= 1000`
- Each element is an integer in the range `-10^6` to `10^6`
