# Installation: JDK, IDE, and Build Tools

Before writing a single line of Spring Boot code, your machine needs three things in place: a JDK 17+, a capable IDE, and Maven or Gradle as your build tool. Getting each component installed correctly and verified upfront saves hours of "it works on my machine" problems later.

---

## 1. Install the JDK

Spring Boot 3 requires **Java 17 or later**. The recommended distribution for most developers is **Eclipse Temurin** (formerly AdoptOpenJDK), maintained by the Adoptium working group. It is free, LTS-backed, and available for every major OS.

### Windows

```bash
# Using winget (Windows 10/11)
winget install EclipseAdoptium.Temurin.17.JDK

# Verify
java -version
javac -version
```

### macOS

```bash
# Using Homebrew
brew install --cask temurin@17

# Verify
java -version
javac -version
```

### Linux (Debian / Ubuntu)

```bash
# Add Adoptium repository
wget -qO - https://packages.adoptium.net/artifactory/api/gpg/key/public | sudo apt-key add -
echo "deb https://packages.adoptium.net/artifactory/deb $(lsb_release -sc) main" \
  | sudo tee /etc/apt/sources.list.d/adoptium.list

sudo apt update
sudo apt install temurin-17-jdk

# Verify
java -version
javac -version
```

Expected output (version numbers may differ in the patch):

```
openjdk version "17.0.11" 2024-04-16
OpenJDK Runtime Environment Temurin-17.0.11+9 (build 17.0.11+9)
```

> **Common mistake:** Installing a JRE instead of a JDK. The JRE does not include `javac` and will break compilation. Always install the full JDK package.

## 2. Set JAVA_HOME

Many tools — including Maven — rely on the `JAVA_HOME` environment variable.

| OS | How to set |
|----|-----------|
| Windows | System Properties > Environment Variables > New system variable `JAVA_HOME` = `C:\Program Files\Eclipse Adoptium\jdk-17...` |
| macOS / Linux | Add `export JAVA_HOME=$(/usr/libexec/java_home -v 17)` to `~/.zshrc` or `~/.bashrc`, then `source` it |

Verify:

```bash
echo $JAVA_HOME        # macOS / Linux
echo %JAVA_HOME%       # Windows CMD
```

## 3. Choose an IDE

| IDE | Best for | Spring Boot support |
|-----|----------|-------------------|
| **IntelliJ IDEA (Community / Ultimate)** | Most Spring developers | Built-in Spring Initializr, run configurations, live reload |
| **VS Code + Extension Pack for Java** | Lightweight, polyglot teams | Spring Boot Extension Pack covers most needs |
| **Eclipse + Spring Tools 4** | Teams already on Eclipse | First-class Spring tooling, slightly more setup |

**Recommended:** IntelliJ IDEA Community Edition is free and provides the best out-of-the-box experience for Spring Boot projects.

Install IntelliJ IDEA via the [JetBrains Toolbox App](https://www.jetbrains.com/toolbox-app/) — it handles updates and multiple IDE versions cleanly.

## 4. Install Maven

Spring Boot projects generated by Spring Initializr ship with a **Maven Wrapper** (`mvnw`), so a system-wide Maven install is optional but recommended for command-line work.

### Windows

```bash
winget install Apache.Maven
```

### macOS

```bash
brew install maven
```

### Linux (Debian / Ubuntu)

```bash
sudo apt install maven
```

### Verify

```bash
mvn -version
# Apache Maven 3.9.x (...)
# Java version: 17.x.x, vendor: Eclipse Adoptium
```

> **Best practice:** Even when a project has `mvnw`, keep a system Maven installed so tools like CI pipelines and shell scripts work without the wrapper.

## 5. Verify the Full Stack

Create a minimal `pom.xml` and compile a "Hello" class to confirm Java, Maven, and your IDE all talk to the same JDK:

```xml
<!-- pom.xml (minimal smoke test, not a Spring Boot project yet) -->
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
                             http://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.example</groupId>
  <artifactId>smoke-test</artifactId>
  <version>1.0-SNAPSHOT</version>
  <properties>
    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
  </properties>
</project>
```

```java
// src/main/java/com/example/Hello.java
package com.example;

public class Hello {
    public static void main(String[] args) {
        System.out.println("Java " + Runtime.version() + " — ready for Spring Boot!");
    }
}
```

```bash
mvn compile exec:java -Dexec.mainClass="com.example.Hello"
# Output: Java 17.0.x — ready for Spring Boot!
```
