# Video: Linked Lists — Singly, Doubly, and Circular

This video builds singly and doubly linked lists from scratch, demonstrates insertion and deletion at the head, tail, and middle, and then tackles the classic reversal algorithm step by step.

**Key takeaways:**
- Pointer manipulation — tracking `prev`, `cur`, and `next` — is the core mental model for every linked-list problem.
- Doubly linked lists trade an extra pointer per node for O(1) deletion when you already hold the node reference.
- Floyd's cycle-detection algorithm (fast/slow pointers) elegantly detects loops without extra memory.

- 10:00 — Insertion and deletion (head, tail, arbitrary position)

- 32:00 — Doubly linked lists and sentinel nodes
- 42:00 — Floyd's cycle detection and the fast/slow pointer pattern
